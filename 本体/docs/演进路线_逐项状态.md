### 0.5.2 实现清单

**新增文件**
- `本体/vfs.h` / `本体/vfs.c`：freestanding VFS 层。挂载表 `vfs_init/mount/umount/mounted/count`，路径解析 `vfs_resolve`（最长前缀、整段匹配），统一 `vfs_read_path/stat_path/list_path`；内置 devfs、procfs 两个 ops 后端。字符串/数字格式化全手写，不依赖 libc/malloc。
- `本体/test_vfs_host.c`：**35/35**，覆盖挂载/重复挂载/路径负例、最长前缀嵌套挂载、procfs 数据回调可变（非常量）、devfs 读写、umount 后交回老路径、挂载表满负例。
- `本体/user/u56_vfs.c`：-nostdlib EL0 程序，走 `SYS_vfsread`/`SYS_vfsinfo` 读伪文件，输出 `[R56] key=value`；含老路径 `open/read /etc/hostname` 对照。`sys_exit` 体面退出。
- `本体/test_round56.py`：双路判据（TCG / 真机 KVM），本地 TCG **19/19**。

**修改文件（严格最小侵入）**
- `本体/kernel.c`：① include `vfs.h`；② procfs 数据源回调（`pf_mem_total_kb` 等接 `mm_stat`/`tick`/`smp_online`/`rtc_now`，真实数据非硬编码）；③ `cmd_cat`/`cmd_ls` 各加一个**挂载点钩子**——仅 `fs_lookup<0` 且命中挂载点才走 VFS，老路径一行不改；④ 新增 `SYS_vfsread`(20)/`SYS_vfsinfo`(21) 分发；⑤ `kernel_main` 在 `fs_init` 后**静默**挂载 `/proc` `/dev`（不进启动日志基线）；⑥ `LOS_VERSION` 更新为 56.0（不进基线）。**0 个新增 `cmd_*`**。
- `本体/usys.h` / `本体/user/user.h`：新增 20/21 号 syscall 编号与封装。
- `本体/build.sh`：`KERN_SRCS` 加 `vfs.c`；编 `u56vfs.elf`「只编不内嵌」。

### 0.5.3 关键设计决策（都写进代码注释）

1. **老路径优先**：`fs_lookup` 命中即返回，VFS 完全不参与；`/etc/hostname`、`/nope` 等 29 条基线路径不会进入 VFS 钩子。
2. **VFS 不接管 open/read fd 层**：`SYS_open`(2)/`SYS_read`(3) 逐字不动（第 55 轮教训：老 syscall 零扰动）。伪文件用专用 `SYS_vfsread` 读，语义清晰、不动 fd 对象层。
3. **procfs 数据源回调注入**：`vfs.c` 不依赖 `kernel.c` 全局，通过 `procfs_set_source()` 注入 `mm_stat`/`tick`/`ncpu`/version 回调；宿主单测用假数据替代，验证「读的是回调而非常量」。
4. **挂载静默**：开机挂载不打任何日志，避免污染 golden 的启动日志逐字比对。
5. **零 malloc**：挂载表固定 8 项静态数组，伪文件内容现场生成到调用方缓冲，不占动态堆、不占 BSS 大块（仅增约 4KB，余量仍 20KB）。

### 0.5.4 诚实边界（第 56 轮）

1. **「跨挂载点 cp」未做全**：文档验收写「跨挂载点 `cp`」，本轮只做到**跨挂载点读**（loongfs 文件 vs procfs/devfs 伪文件用不同后端读出），但**没有实现 `cp` 把文件从 loongfs 写到 procfs 挂载点**（procfs 是只读伪文件，语义上也不该可写）。完整 `cp` 依赖 VFS 写接口 + `/mnt` 真实挂载，留后续轮次。
2. **VFS 是渐进式，不是全量替换**：`fs.c` 没有「降级为 loongfs 后端、所有 `fs_*` 调用改 `vfs_*`」——老命令仍直接调 `fs_*`，VFS 只接管 `/proc` `/dev` 两个新挂载点。文档 §3.1 的「加 FAT32/EXT2 不改上层」这一收益**尚未兑现**（需把上层全改 vfs_*）。
3. **`/proc` 是简化版**：只有 5 个固定伪文件，`uptime` 的空闲秒恒 0（诚实标注），非完整 Linux procfs。
4. **2.3 shell 迁出内核仍未做**：见 §零点一 0.4 第 1 条，依赖第 57 轮进程模型。
5. **真机 KVM 双路未复验**：本地 x86_64 无 aarch64 KVM；NAS SSH 通道本轮 21:08 探测端口 56484 仍 `NoValidConnectionsError`（延续第 54/55 轮）。报告 KVM 列「—」= 未执行。
6. **用户态程序不随 ISO 分发**：`/home/u56vfs` 由判据脚本经 b64 临时注入。

| ③ 11 个 syscall 到位 | stat/fstat/dup/dup2/pipe/getpid/mkdir/unlink/rename/kill/getcwd 全部实现；另补 chdir/getdents/creat 共 14 号 | ✅ 超出 |

| ⑥ 关键结论可复现 | `test_round55.py` 25 项独立重算 | ✅ |

### 0.2 实现清单（摘要）

- `usys.h`/`usysfd.h/c`：syscall 6~19 ABI + 统一 fd 表 + 环形 pipe（kmalloc 分配）；`test_usysfd_host.c` 57/57。
- `user/u55_util.h`/`u55_systest.c`/`u55_sh.c`：两个 EL0 程序。`test_round55.py` TCG 25/25。
- `kernel.c`：0/3/4 号 syscall 插入 pipe 钩子（`is_ufd_obj` 仅 fd 真指向 pipe 时为真）；新增 6~19 分发；`run_userprog` 装载前 `ufd_reset`；开机 `ufd_init`。**0 新增 cmd_***。

### 0.3 关键设计决策

1. **0~5 号 syscall 逐字不动**：老 ELF 与 `test_stage5b_elf.py` 33 项判据全依赖它。
2. **cwd 隔离**：syscall 用独立 `g_ucwd`，不改 `path_resolve` 本身。
3. **用户程序不进内核镜像**：经 `b64in` 注入 `/home`，不碰启动日志/`ls /bin`/`df`。
4. **fs 返回值规整**：成功 ino(>0) → 0，失败(<0) → -1。
5. **`fs_rename` 不支持移动目录**（-3）：rename 判据改用文件，加 `SYS_creat` 自洽。

### 0.4 诚实边界（第 55 轮）

1. **2.3 shell 迁出未做**：`u55sh` 是管道演示程序，不是交互 shell；依赖第 57 轮进程模型。
2. **管道不是并发多进程**：单进程「写满→关写端→读」分阶段装配。
3. **`kill` 占位语义**：pid!=1 拒、pid==1 TERM 只回 0 不真杀。
4. **`getdents` 路径+缓冲简化接口**：非 fd 型 `getdents64`。
5. **第 54 轮 7 个 `cmd_*` 技术债仍在**：零新增但未迁出。
6. **真机 KVM 双路未复验**：见 §零点五 边界 5。
7. **用户态程序是测试资产**：不随 ISO 分发，无 `PATH`/`/bin/sh`。

## 九、诚实边界（累计列出）

1. **不是「全部基本解决完成」**：进程模型、fork/exec/wait、用户态交互 shell、TTY/信号、
   socket、ZFS-lite、Jail-lite 等架构级能力未实现。三轮只做实「可真实落地+可量化验收」的
   地基、syscall 扩容、VFS+伪文件系统与低风险增量项。
2. **2.2 验收②未满足**：`stat` 仍显示开机秒数（保基线），真实墙钟在 `wall`/`ls -l`；ISO 内存盘重启不持久。
3. **2.3 shell 迁出内核未做**：`u55sh` 是管道演示程序，不是交互 shell；依赖第 57 轮进程模型。
4. **第 54 轮 7 个 `cmd_*` 技术债仍挂账**：第 55/56 轮零新增但未迁出（见 §六）。
5. **管道是单进程分阶段装配**：非三进程并发；`kill` 是占位语义。
6. **`vmalloc` 未做**：映射与内核栈用途随第 57 轮进程模型。
7. **第 56 轮「跨挂载点 cp」与 VFS 全量替换上层未做**：见 §零点五 边界 1/2；procfs 只读、简化版。
8. **真机 KVM 双路三轮均未复验**：本地 x86 无 aarch64 KVM，NAS SSH 通道 21:08 探测仍不通。报告 KVM 列「—」= 未执行。
9. **新增能力未进 `help`/基线**：存在性由 test_round54.py 22 项 / 55 项 25 项 / 56 项 19 项判据单独证明。
10. **用户态程序不随 ISO 分发**：`/home/u55*`、`/home/u56vfs` 由判据脚本经 b64 临时注入。
