# 灵珑 OS · 桌面系统（Project: LOONGOS DESKTOP）

> 目标：把 LoongOS 从「串口 shell」变成一台**能日常打开、有窗口、有鼠标、有应用**的图形操作系统。
> 本篇是架构 + 分期路线 + 开工清单。所有设计都对着现有代码（kernel.c 2493 行 / fs.c 672 / usb_kbd.c 1049）说话。

---

## 一、现状盘点（为什么"能做"）

| 能力 | 现状 | 位置 |
|---|---|---|
| 帧缓冲输出 | ✅ 已有，GOP 参数经 bootinfo 传入，8x16 英文 + 16x16 中文点阵 | `kernel.c:133` / `font8x16.h` / `font_cjk.h` |
| 鼠标 | ❌ 无 | —— |
| 键盘 | ✅ USB HID boot 键盘（xHCI 枚举 + 报告解析） | `usb_kbd.c` |
| 中断/定时器 | ✅ GICv2/v3 + 10Hz tick + 抢占调度 | `kernel.c:handle_irq` |
| 文件系统 | ✅ 自带 fs（内存盘 / 磁盘持久） | `fs.c` |
| 用户程序 | ✅ ELF 加载 + `run`（只有 write/exit 两个系统调用） | `kernel.c` |
| 网络 | ✅ virtio-net + TCP | `virtio_net.c` / `tcp.c` |
| 内存 | ⚠️ 无堆分配器，全是静态 BSS | 需要新增 `kmalloc` |

**结论**：图形输出、键盘、文件系统、定时器都在，缺的是**鼠标、窗口管理、绘图抽象、应用框架**。这正好是"桌面"的四块。

### 2.1 `gfx.h` — 绘图原语（不依赖窗口，纯像素）

```c
typedef struct { u32 x, y, w, h; } rect_t;

void gfx_init(void);                          /* 读 bootinfo，算 fb 参数 */
void gfx_fill(rect_t r, u32 rgb);             /* 裁剪后填充 */
void gfx_rect(rect_t r, u32 rgb, int thickness);
void gfx_line(int x0, int y0, int x1, int y1, u32 rgb);
void gfx_blit(rect_t dst, const u32 *src, u32 src_w);
void gfx_text(int x, int y, const char *s, u32 fg, u32 bg);  /* ASCII + CJK 混排 */
int  gfx_text_w(const char *s);
void gfx_clip_push(rect_t r);  void gfx_clip_pop(void);      /* 裁剪栈（8 层） */
void gfx_damage(rect_t r);     void gfx_present(void);       /* 脏矩形合并重绘 */
```

**关键决策：不做全屏双缓冲，做脏矩形。**
理由：TCG 软件模拟下，1024×768×4 = 3MB 的全屏拷贝每帧要几十毫秒；脏矩形只重画变化区，光标移动只重画两小块。
**例外**：壁纸/背景这类整屏重绘，走一次性 blit。

### 2.2 `input.h` — 统一事件

```c
enum { EV_KEY, EV_MOUSE_MOVE, EV_MOUSE_DOWN, EV_MOUSE_UP, EV_MOUSE_WHEEL };
typedef struct {
    u16 type; u16 x, y;        /* 鼠标：屏幕坐标 */
    u16 button;                /* 1=左 2=右 4=中 */
    u16 key;                   /* 键：ASCII 或扩展码 */
} event_t;

int  input_poll(event_t *ev);  /* 1 = 取到事件 */
```

来源：
- 键：现有 `ring_pop()`（UART + usb_kbd）→ 转 `event_t`（UART 也走这里，方便远程调试）
- 鼠标：**新增 `usb_mouse.c`**，复用 `usb_kbd.c` 的 xHCI 枚举代码

### 2.3 `wm.h` — 窗口系统

```c
typedef struct window {
    rect_t   frame;                       /* 含标题栏 */
    char     title[32];
    u32      bg;
    void   (*on_draw)(struct window *w);  /* 应用自己画内容（用 gfx_*） */
    void   (*on_event)(struct window *w, const event_t *e);
    int      visible, focused, closable;
    struct window *next;                  /* z 序：表头 = 最上层 */
} window_t;

window_t *wm_create(const char *title, rect_t r, void (*draw)(window_t*));
void      wm_destroy(window_t *w);
void      wm_focus(window_t *w);
void      wm_invalidate(window_t *w);     /* 标脏 → 下帧重画 */
void      wm_run(void);                   /* 主循环：poll → 分发 → present */
```

**绘制顺序**：壁纸 → 从最底层窗口向上 → 任务栏 → 鼠标指针。

**裁剪**：每画一个窗口，先 `gfx_clip_push(内容区)`，画完 pop。窗口互相遮挡由 z 序 + 裁剪保证。

### 2.4 应用模型（第一阶段：内核内回调）

不搞进程隔离——先跑通体验。应用 = 一个「draw 回调 + event 回调」的结构体，
放在 `apps/` 各自一个 .c 文件，编译进内核。

**第二阶段（可选）**：EL0 用户进程 + 绘图系统调用（`fb_map` / `draw` / `event_wait`）。
这一步才叫真"操作系统"，但工作量大，且现有 EL0 只有 write/exit，要先补一堆 syscall。

## 四、关键技术风险（提前排）

| 风险 | 说明 | 对策 |
|---|---|---|
| **鼠标从哪来** | aarch64 `virt` 没有 PS/2；只能用 USB | xHCI 代码已有，扩一个鼠标接口解析；**优先 `usb-tablet`（绝对坐标）**，无加速度、不飘 |
| **TCG 下慢** | 每个像素都要模拟 | 脏矩形 + 默认 800×600 + 只重画变化区；VM 里用 KVM 就无压力 |
| **BSS 涨 → USER_BASE 要挪** | 老坑：`build.sh -Ttext` 必须跟 `kernel.c USER_BASE` 同步 | 每期构建后 `nm kernel.elf | grep vectors` + 跑 `test_iso_boot.py` |
| **无本地验证** | NAS 铁律：不起 QEMU | 只能编译零警告 + 用户 VM 实测；关键逻辑（裁剪/命中测试）写成**纯函数**，用宿主 `gcc` 单测（`test_wm_host.c`） |
| **字体只有点阵** | 8x16 / 16x16，缩放难看 | 先接受；后期做 2x 整数放大（最近邻）不引入抗锯齿 |

**宿主单测思路（不用 QEMU 也能验）**：`gfx_*` 和 `wm_*` 里凡是"算坐标/算裁剪/命中测试"的部分抽成纯函数，
在 NAS 上直接用 `gcc` 编译 `test_wm_host.c` 跑断言（和现有 `test_fs_host.c` 同一套路）。

## 六、开机形态变化

- 现在：`-kernel` 直载 → 串口 shell
- 之后：**默认进图形桌面**；串口照旧输出日志（保留调试通道），加 `-noshell` / 启动参数可选进纯 shell
- 用户 VM 需要加：`<input type='tablet' bus='usb'/>` 或 QEMU `-device usb-tablet`
  （`usb-kbd` 已有，鼠标再加一个；两者可以共存）

## 七、P1 开工清单（第一批代码）

1. `gfx.h`：接口全部定下来（见 2.1）
2. `gfx.c`：
   - `gfx_init()` 从 bootinfo 取 base/width/height/stride/pixfmt，兼容 32bpp
   - `clip` 栈（8 层）+ 所有图元先过裁剪
   - `gfx_fill_rect` 按 32bpp 逐像素写（注意现有代码按 u64 双像素写，pixfmt 可能非 32bpp，要探测）
   - `gfx_text` 复用现有 `font8x16.h` / `font_cjk.h`
3. `desktop.c`：`desktop_run()` = 画壁纸 → 画一个测试窗口 → 画任务栏 → 主循环 `wfi`
4. `kernel.c`：`main()` 末尾改成 `desktop_run();`（保留 `shell` 命令可返回）
5. `build.sh`：加 `gfx.c desktop.c`
6. 宿主测试 `test_wm_host.c`：裁剪求交、窗口命中、z 序插入

**P1 完成判据**：VM 启动后屏幕是「深色壁纸 + 顶部任务栏 + 一个带标题栏的空窗口」，串口仍然有完整日志。
