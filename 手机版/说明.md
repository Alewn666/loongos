# 灵珑系统 | LoongOS —— 在安卓手机上运行

> 这是我自己写的操作系统（64 位 ARM，裸机内核，带 shell、文件系统、用户程序、网络）。
> 手机本身跑不了裸机内核（引导锁 + 没驱动），所以做法是：**在 Termux 里开一台 aarch64 虚拟机跑它**。
> 手机上你能看到它真的开机、真的敲命令、真的存文件 —— 这就是"在手机上跑玲珑 OS"。

---

## 一、装环境（只做一次）

1. **装 Termux** —— 别用应用商店版本（已废弃）。
   从 **F-Droid** 或 **GitHub releases**（termux/termux-app）装。
2. Termux 里执行：

```sh
pkg update -y && pkg upgrade -y
pkg install -y qemu-system-aarch64-headless tar
```

3. 给 Termux 关掉电池优化（设置 → 应用 → Termux → 电池 → **无限制**），
   否则跑一半会被系统杀掉。

## 二、放文件并启动

把整个 `loongos-phone` 文件夹放到手机里（例如 `下载/` 下解压），然后在 Termux 里：

```sh
termux-setup-storage                      # 第一次：允许访问文件
cd ~/storage/downloads                    # 进入手机"下载"目录
tar xzf loongos-phone.tar.gz              # 解压
cd loongos-phone
sh start.sh                               # 起飞
```

启动后会先看到内核 banner，然后进入 `login:` → 敲 `root`，口令 **`loong2026`**
（`demo` / `demo2026` 也可以）。看到 `#` 就是进到它自己的 shell 了。

> 退出虚拟机：**Ctrl + A** 松手，再按 **X**。
> Termux 键盘上方那排额外按键里有 `CTRL`，点一下再点 A、X 即可。

## 三、进去以后玩什么

```sh
help          # 全部命令
ls  /  home /etc        # 它自己的文件系统（不是 Android 的）
cat /etc/hostname
write /home/a.txt hello # 写文件
whoami
run /bin/cat /home/a.txt   # 跑它自己的 ELF 用户程序
bench         # 性能跑分（顺便量一下你手机的虚拟机有多快）
disks         # 看虚拟磁盘
tcp get 192.168.1.100 22   # 虚拟机里发 TCP（要网卡，见下）
```

想让它联网：给 `start.sh` 加一行 `-netdev user,id=n1 -device virtio-net,netdev=n1`，
进去后 `net dhcp`，就能 ping 通家里 NAS。

## 四、文件能不能留住？

`disk.img` 是一块 128MB 的虚拟硬盘。**第一次启动会自动格式化**，屏幕上会出现：

```
[fs  ] 数据分区是空白（首次使用），自动格式化 ...
[fs  ] MOUNTED-DISK lba=2048 blocks=32512 (formatted)
```

之后你 `write` 的文件、改的 `/etc`，关掉虚拟机再开都还在。
如果哪天想回到干净状态：删掉 `disk.img` 再启动一次（或 `sh make-disk.sh` 重建）。

## 五、提速（可选）

- 默认是 **TCG 软件模拟**：通用、不要 root，慢但完全够用（这个内核很小）。
- 部分机型开放了 `/dev/kvm`（Android 13+ 的 pKVM），可以试：
  ```sh
  ACCEL=kvm sh start.sh
  ```
  能起来就快很多；起不来就退回默认（脚本不会破坏任何东西）。
- 想更流畅：`MEM=128 sh start.sh`（内核只吃 128MB，内存给大了反而慢）。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| `qemu-system-aarch64: not found` | `pkg install -y qemu-system-aarch64-headless` |
| 启动一半 Termux 被杀 | 关电池优化；或 `termux-wake-lock` |
| 屏幕上中文变 `?` | 已知问题（串口编码），英文和数字正常；敲 `whoami` 等命令不受影响 |
| 敲字没反应 | 点一下屏幕唤出键盘；确认不是卡在 `login:` 等输入 |
| 想拷文件出来 | 虚拟机里的文件在 `disk.img` 内，暂不支持直接导出（下一步做） |
